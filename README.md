# Agrimind 
Farmers need to make time-sensitive decisions in response to weather changes and often struggle with accessing valuable crop data needed to maximize yields. Agrimind is an AI-powered application designed to help farmers in these respects by analyzing weather data, crop requirements and market intelligence to generate a smart recommendation.

## Features - 
An easy-to-use interface.
Smart recommendations based on location and weather reports.


## Tech-Stack -
Frontend - React.js + Vite
Backend - FastAPI + Pydantic
Synthesiser LLM - Gemini
External API - OpenWeatherAPI
